# Avance PD Docs

This folder contains the public, repo-safe documentation for the Avance Work Companion app.

Private operational notes, client details, credentials, archives, raw references, and agent prompts must stay out of Git. Use generic examples only.

## Core Docs

- `DEVELOPER_README.md` - local setup, build, and extension notes
- `TODO.md` - documentation-facing project tracker that mirrors the root TODO
- `vision.md` - product principles, scope, and privacy rules
- `USER_GUIDE.md` - daily use guide for Josh
- `PROFESSIONAL_DEVELOPMENT.md` - PD workflow and learning review guidance
- `UI_UX_AND_TONE_GUIDE.md` - app tone, UX, accessibility, and visual principles
- `SAMPLE_SEED_DATA.md` - seed-data policy and safe sample-data rules
- `HEALTH_AND_OUTDOORS.md` - Health & Outdoors design, privacy, and email architecture notes
- `DEPLOYMENT.md` - private deployment and local preview guidance
- `SYNC_PLAN.md` - optional low-risk sync plan
- `QA_CHECKLIST.md` - build, navigation, persistence, and privacy checks
- `ROADMAP.md` - deferred future work and guardrails
- `AWESOME_IDEAS_AND_VIBE_CODER_PLAN.md` - feature ideas, upgrades, and implementation guidance
