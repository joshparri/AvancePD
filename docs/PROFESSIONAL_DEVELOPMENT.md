# Professional Development Workflow

The PD workflow is designed to turn MSP work into manager-safe growth evidence.

## Weekly PD Loop

1. Pick one skill area to notice during the week.
2. Practise one relevant MSP scenario or micro-learning card.
3. Capture one generic learning item after a shift.
4. Add evidence only when it is privacy-safe.
5. Review confidence and next action at the end of the week.

## Learning Machine Loop

The next product direction is:

`work -> learning seed -> KB field card -> active recall -> scenario drill -> ticket note drill -> spaced review -> evidence`

Use Work Companion to capture learning seeds during shifts. Use Avance PD as the learning cockpit for KB field cards, flashcards, scenario practice, ticket-note drills, confidence tracking, and manager-safe evidence.

## Avance Shift Review Prompts

- What did I practise today?
- What did I handle more independently than last time?
- What did I need help with?
- What should I review before the next shift?
- What is safe to include in my Evidence Pack?

## Manager-Safe Evidence

Good evidence:

- uses generic categories
- describes behaviour, process, and learning
- avoids client names and operational details
- shows follow-through and judgement

Avoid:

- ticket text
- screenshots
- IP addresses or hostnames
- credentials
- private personal or medical details
