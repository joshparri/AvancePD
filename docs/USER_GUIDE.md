# User Guide

This guide describes a simple Avance shift routine.

## Start Of Shift

1. Open the app.
2. Check `Dashboard` for next shift context and open follow-ups.
3. Open `Avance Workday`.
4. Use the start-of-day checklist.
5. Set a generic focus, such as "triage queue", "follow-ups", or "documentation".
6. Check the `Healthy MSP Shift` panel for the next wellbeing action.

## During The Shift

- Use quick capture for generic notes, follow-ups, and learning.
- Use `Tasks` for actions that must survive the next shift gap.
- Use `Knowledge` and `Playbooks` for reusable, non-sensitive patterns.
- Use `Ticket Notes` to practise clean summaries without copying real ticket text.
- Use `Health & Outdoors` for water, outdoor time, eye breaks, movement, and shutdown prompts.

## Quiet Or Overwhelmed Moments

- Use Avance Workday's quiet-time PD suggestions when there is a small gap.
- Use "urgent ticket mode" in Health & Outdoors when reminders need to back off.
- Use the 2-minute reset when you need to return to one clear next action.

## End Of Shift

1. Review open tasks.
2. Capture any generic learning.
3. Update evidence where useful.
4. Use the Health & Outdoors shutdown prompt: close loops, note next actions, breathe, and let work stay at work.

## Using the Avance KBs

- The local KB folder at `docs/Avance KB_s` is reference-only.
- Use it to identify the correct topic category for a captured issue, such as device enrollment, remote access, cloud identity, security policy, or printer/phone setup.
- Mark work logs in App 1 with the related KB topic or skill area when it is learning-worthy.
- In App 2, use the KB category to choose a matching scenario, skill card, or evidence pack item.
- Keep the KB content local and generic in app docs; do not copy private or customer-specific material into public GitHub files.

## Using the KB Learning Session

- The KB Learning Machine should feel like a lesson, not a long reference page.
- Start with the hero prompt: “What are we learning today?”
- Follow the session flow: learn, quiz, recall, practical task, ticket-note drill, and evidence.
- Use short collapsible summaries and expand only the details you need.
- Save your quiz answer, recall response, task plan, ticket note, and evidence locally.
- If AI coach feedback is available, it should be handled server-side and should not expose the API key in the browser.
- Treat KB cards as source material for a lesson, not as the destination.

## Privacy Reminder

Keep client details, credentials, IPs, hostnames, copied tickets, screenshots, and private medical notes out of the app.
